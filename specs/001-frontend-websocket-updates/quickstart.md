# Quickstart: 검증 가이드

## 사전 조건

- qssb 서버 기동(콘솔 인증 가능 상태), 크론 트리거가 등록된 배치 Job 1개 이상.
- 프런트엔드: `cd quartz-manager-frontend && npm ci`.

## 1. 단위 테스트

```bash
cd quartz-manager-frontend && npm test
```

기대: 서비스 spec(재연결 설정), 매니저 컴포넌트 진행 표시 케이스 통과.

## 2. 수동 시나리오 (spec 대응)

1. 콘솔 로그인 후 트리거 선택 → 작업 "Trigger Now" → **새로고침 없이** 이벤트 스트림에 로그 1건(INFO/ERROR) 표시 (US1, SC-001).
2. 같은 시점 진행 영역이 "대기 중"에서 이전/다음 실행 시각 표시로 전환, `-1%` 미노출 (US2, SC-002).
3. 트리거 A→B→선택 해제 반복 후 다른 트리거 메시지가 섞이지 않음 (US4, SC-003).
4. 서버 중지 후 재기동: 상태 칩이 재연결 중→연결됨으로 변하고, 다음 실행 로그가 다시 수신됨 (US3, SC-004).
5. 세션 쿠키 삭제 후 새로고침: 연결 실패 안내 표시, 재시도 간격이 늘어남 (FR-009, SC-005).
6. 기존 REST 기능(트리거/작업 조회·수정)이 동일하게 동작 (SC-006).
